# 📊 Enterprise POS & Advance Billing Management Portal

A high-performance Single Page Application (SPA) engineered for high-volume desktop Point of Sale (POS) environments. Built with modern vanilla JavaScript (ES6+), Vite, and Firebase, this system provides a seamless experience for cashiers while offering powerful analytics and inventory management for administrators.

## 🚀 Key Features

### 👤 Role-Based Access Control (RBAC)
* **Admin Dashboard**: Comprehensive analytics, daily revenue reports, inventory management, and system configurations.
* **Cashier Interface**: Streamlined, zero-latency checkout interface built specifically for fast-paced retail or hospitality environments.

### 💳 Real-Time Transaction Processing
* **Bill Holding & Retrieval**: Temporarily hold active bills and retrieve them at any time without losing line items.
* **Flexible Payments**: Support for multiple payment methods (Cash, Card, Digital Wallets).
* **Discounts & Dynamic Calculations**: Apply line-item or order-level discounts with instant total recalculation.
* **Client-Side PDF Receipts**: Generate and download printable receipts on demand.

### 📦 Inventory & Data Management
* **Firebase NoSQL Database**: Real-time sync for persistent bill histories, product catalog, and revenue tracking.
* **Live Inventory Updates**: Automatic stock adjustments upon transaction completion.

## 🛠️ Tech Stack

* **Frontend**: JavaScript (ES6+), HTML5, CSS3
* **Build Tool / Bundler**: Vite
* **Backend / Database**: Firebase
